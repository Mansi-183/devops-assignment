1. Five DevOps Concepts

 **1. Continuous Integration (CI)**
- Developers frequently merge code into a shared repository.
- Automated tests run on every change.
- Ensures early detection of bugs.
- Helps maintain code stability.
- Tools: GitHub Actions, Jenkins, GitLab CI.

 **2. Continuous Deployment (CD)**
- Automatically deploys tested code to production.
- Eliminates manual deployment effort.
- Ensures faster release cycles.
- Helps maintain consistent deployment practices.
- Tools: Jenkins, GitHub Actions.

 **3. Version Control (Git)**
- Tracks changes in code over time.
- Allows rollbacks, branching, merging.
- Enables collaboration among developers.
- Git + GitHub helps in maintaining project history.
- Essential for DevOps workflows.

 **4. Containerization (Docker)**
- Packages application + dependencies into one image.
- Runs consistently on any system.
- Lightweight and fast.
- Supports microservices architecture.
- Dockerfiles are used to define how containers are created.

 **5. Infrastructure as Code (IaC)**
- Servers and infrastructure are managed using code.
- Ensures automation and repeatability.
- Reduces manual configuration errors.
- Helps scale systems faster.
- Tools: Terraform, Ansible, CloudFormation.
